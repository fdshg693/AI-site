# AI-site

fdshg693/AI のスキル公開サイト（skills-site、Astro＋Azure Static Web Apps）とツールドキュメントサイト（tools-site、VitePress＋GitHub Pages）。

このリポジトリは [fdshg693/AI](https://github.com/fdshg693/AI) のサブモジュール（`site/`）です。生成・検査・ワークスペース（uv / pnpm）はアンブレラ側にあるため、アンブレラから clone して使います。

```sh
git clone --recurse-submodules https://github.com/fdshg693/AI.git
```
